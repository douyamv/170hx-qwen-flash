# Next 优化版部署与 262K 真机结果

优化版已部署并保持运行。当前模型是 Qwen3.8-Flash-Next UD-Q4_K_XL，三张 CMP170HX 40 GiB，Q8 KV，MTP 3，实际上下文限制 262144。Huihui 服务已暂停，没有恢复为主模型。

## 实测速度

| 运行 | Decode token/s | 用途 |
|---|---:|---|
| 此前原版满上下文记录 | 18.35 | 原版参考，只测过一次 |
| 优化版首次全长运行 | 32.05 | 未采集、无检测到的后台测速干扰 |
| 优化版干净预热复测 1 | 36.73 | 正式结果 |
| 优化版干净预热复测 2 | 36.29 | 正式结果 |
| 优化版干净预热复测 3 | 36.44 | 正式结果 |
| 优化版两次受后台测速影响 | 35.44 / 34.06 | 已剔除 |
| 开启 CUPTI 采集 | 27.62 | 仅用于诊断，不当作正常速度 |

干净预热中位数 36.44 token/s，相对已有原版记录约 1.986 倍，提升约 98.6%。首次优化版运行也比原版参考快约 74.7%。这不是交错执行的严格 A/B：原版只有此前的一次满上下文记录，缓存/预热条件不完全相同。下载、模型加载与首字前预填充时间均不计入 decode。

所有本轮长测试实际输入均为 261888 token，上限设为生成 256 token。优化版在引擎上下文容量停止条件触发时返回 255 token，缓存记录为 262143；此前原版返回 256。速度按各次实际返回数量计算。输入没有裁剪，上下文配置没有缩短，不能把输出差一 token 隐去。

首次完整冷输入首字约 887.7 秒；后续复用 261884 个前缀 token，首字约 0.96–1.14 秒。这些首字时间不能与不同前缀缓存条件的原版直接比较。

## 已接入且在真实模型中确认执行

- 长上下文、小批量 QSA Top-K 拆成逐行排序。
- QSA 历史收集、四项平均、RMSNorm 与权重乘法融合。
- QSA 块分数展开与掩码相加融合。
- 带适用条件检查的单序列连续缓存 CPU 输入快路径。
- 按已测试形状收集选中 K/V，再执行小缓存注意力。
- SM80、Q8、256 维、GQA=12 的长上下文单 query 直接选择 MMA 注意力内核。

全部由 NEXT_QSA_OPT=1 控制；长上下文阈值为 131072，相关小批量分支限制为不超过 8 个 query。其他形状保留原路径。此前 IQ4_NL 160 宽度词表 GPU 取行修复、关闭大文件 mmap 预读的开关也保留。

真实采集中的融合历史汇总平均约 0.152 ms/层次调用，分数展开约 0.0130 ms，CPU QSA 输入构造平均约 0.917 ms/批次。独立原型的收益在集成后确实出现了。

## 剩余热点

采集只在第一个输出 token 到达后开启，覆盖生成阶段；共记录 423861 个 GPU 内核、53765 次内存复制、188691 条 CUDA runtime API 活动。记录没有报告丢失；约 98.9% 内核可关联到主模型或 MTP 的 decode 调用。

1. **量化矩阵运算成为最大的 GPU 核时间类别。** 主模型与 MTP 合计约占所有 GPU 内核执行时间之和的 48%。其中主模型 Q8 矩阵向量计算、MoE 的 Q4_K/Q5_1 内核较突出。这个占比不是端到端延迟占比。
2. **主机到 GPU 的传输仍明显。** 采样中合计约 4.084 GB H2D 数据，设备复制活动时间之和约 1.324 秒。常见大块大小为 2 MiB 和 1 MiB，形状与长掩码和索引输入相符，但还没有逐一标注张量来源，不能认定每一笔都是某个特定张量。
3. **同步和图更新值得继续查。** 样本记录了 24549 次 cudaStreamSynchronize、83 次 stream capture、400 次 graph launch。它们包含 GPU 等待和采集扰动，不能全部算成可消除的 CPU 纯开销；频繁重新捕获的具体原因也尚未确定。
4. **MTP 仍有全长缓存访问与反量化工作。** 采集可区分主模型/MTP；MTP 中 Q8 到 F16 的反量化以及完整历史注意力仍有可见耗时。

GPU 内核时间之和约 4.284 秒，三卡 GPU 忙碌时间分别约 0.427 / 1.711 / 2.141 秒。卡间分配也受 26.82 GiB PLE 词表驻留在 GPU0 的限制。以上 CPU/GPU/COPY 时间相互重叠，不能直接相加，也不能把 GPU 空闲简单等同于某一个已证实瓶颈。

## 正确性和边界

- 37 x 29、JSON 排序检查通过。
- 全长输入开头的 ORCHID-7429 在所有优化版长测试中均正确找回。
- 优化版各次长请求输出文本哈希一致，包括开采集的那次。
- 与此前原版的输出并非逐字相同；数学等价路径的浮点运算次序发生变化，当前只做了算子比较和基础输出检查，没有完成系统能力评测。
- 背景带宽测试用 1 秒进程轮询记录；判断重叠时额外扩展前后 1 秒。受干扰的两次低值保留在原始结果中，但不用于正式预热区间。
